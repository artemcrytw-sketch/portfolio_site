САЙТ-ПОРТФОЛИО — ИНСТРУКЦИЯ

1. Распакуйте весь архив в одну папку.
2. Откройте index.html в браузере. Интернет для просмотра локальных страниц не нужен; внешний шрифт Google Fonts может не загрузиться без интернета, но сайт останется читаемым.
3. Не перемещайте отдельно HTML-файлы, папки images и files — структура ссылок рассчитана на их совместное расположение.
4. Перед сдачей замените примерный адрес your-email@example.com и демонстрационные документы на свои материалы.
5. Для публикации загрузите ВСЕ содержимое папки на GitHub Pages, Netlify или другой статический хостинг.

Страницы: index.html, 1.html, 2.html, 3.html. Общие стили: style.css.
